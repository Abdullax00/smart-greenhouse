# 🌱 Умная теплица (Smart Greenhouse)

Инновационный веб-проект презентации автономной умной теплицы с интерактивной 3D-моделью, видеообзором и фотореалистичной галереей.

## ✨ Ключевые особенности

- 🌿 **Интерактивная 3D-модель**: рендеринг и свободное вращение/зум каркаса и конструкции теплицы с помощью [Three.js](https://threejs.org/) (GLTF/OBJ).
- 🎬 **Видеообзор**: плавный обзор экстерьера и архитектурных решений теплицы.
- 📸 **Галерея рендеров**: фотореалистичные кадры в разное время суток с поддержкой полноэкранного модального просмотра (lightbox).
- 📐 **Инженерный CAD-каркас**: демонстрация конструктивных чертежей и пространственной модели.
- 📱 **Полная адаптивность**: поддержка мобильных устройств (iOS Safari, Android), планшетов и широкоформатных экранов.
- ⚡ **Без тяжелых фреймворков**: чистый HTML5, современный CSS3 и оптимизированный ванильный JavaScript.

## 🚀 Быстрый запуск локально

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Abdullax00/smart-greenhouse.git
   cd smart-greenhouse
   ```
2. Откройте `index.html` через любой локальный веб-сервер (необходимо для загрузки 3D-модели без CORS-ограничений):
   - Либо запустите скрипт `start_site.bat`
   - Либо через Python:
     ```bash
     python -m http.server 8000
     ```
   - Откройте в браузере: `http://localhost:8000`

## 🛠 Технологический стек

- **Frontend**: HTML5, CSS3 (CSS Variables, Flexbox, Grid), JavaScript (ES6+)
- **3D Graphics**: Three.js (WebGL, OrbitControls, GLTFLoader)
- **Шрифты**: Google Fonts (Montserrat, Inter)
